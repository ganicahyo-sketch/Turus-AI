# ganicahyo@2026 Automatic Irrigation MQTT App v1.3.0

Aplikasi Android native untuk monitoring dan kontrol ESP32 melalui MQTT.

Fitur: monitoring raw ADC/moisture/pump/duration/volume, tiga mode irigasi, Manual ON/OFF dan Resume Auto, 40 profil tanaman, debit pompa, jadwal SD/ThingSpeak 1–1440 menit, restart, kalibrasi, sinkronisasi waktu, Wi-Fi Enterprise settings, serta Data Explorer SD melalui MQTT (list/view/delete). Download file besar tetap menggunakan dashboard web ESP32.


Versi 1.3.0: mode volume air, interval + volume air, target volume, estimasi volume pada pump events, dan database tanaman diperluas. Data Explorer SD mendukung list/view/delete/download via MQTT.
